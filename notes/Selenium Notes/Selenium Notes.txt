Selenium is used to Automate the web application
Selenium is not used for Desk-Top Base Application id Automation
Selenium was created in 2004 by an ThoughtWorks Engineer.
Selenium web-driver was introduced in 2006

Selenium Grid:
It is tool to use for Parallel Execution.
Selenium grid is Compatible with RC and WD both.
It works like an Execution Engine for Selenium Tests.
Enables simultaneous running of tests in multiple browsers and environments.
Utilizes the hub-and- nodes concept.The hub acts as a central source of Selenium commands to each node connected to it.

Xpath
--------------
Forward Axis:

Self: Select the Current Node
//div/self::* = div fields of 1c

attribute: Select All attribute of current Node
//div/attribute::* =Elements have div HTML tag and atleast one HTML Attribute


Child: Select All children of Current Node
//div[@id='divHomepageContainer']/child::* = Child of all Homepage id 
h
descendant: Selects all descendants(children, grandchildren, etc.)of the current node.
//div[@id='divHomepageContainer']/descendant::*


Descendant -or -self: Select all descendants(children, grandchildren, etc.)of the current node and the current node itself
//div[@id='divHomepageContainer']/descendant-or-self::*

Following-sibling: Select all siblings after the current node
//div[@id='divHomepageContainer']/following-sibling::*

//div[@class="hotAppIcon"]/following-sibling::div[@aria-label='Talent Market Place Opens in a new tab']/div



Following: Selects everything in the document after the closing tag of the current node
//div[@id='divHomepageContainer']/following::*

//div[@class="hotAppIcon"]/following::div[text()="Talent Market Place"]


ReverseAxis:

Parent: Selects the parent of the current node
//div[@id='divHomepageContainer']/parent::*

Ancestor: Selects all ancestors(parent, grandparent, etc.) of the current node.
//div[@id='divHomepageContainer']/ancestor::*

Ancestor -or -self: Selects all ancestors(parent,grandparent,etc.) of the current node and the current node itself
//div[@id='divHomepageContainer']/ancestor-or-self::*

preceding-sibling: Select all siblings before the current node.
//div[@id='divHomepageContainer']/preceding-sibling::*

ChromeOptions:
---------------

1)Headless testing 
-----------------------------------------------------------
- without seeing UI the testing happened in backened is called Headless testing

ChromeOptions option = new ChromeOptions();
options.addArgument("--headless=new");
WebDriver driver = new ChromeDriver(options);

Advantages
----------
1) we can do mutiple tasks (since execution happend backend)
2) faster execution

disadvantage
-----------
1) user cannot see the actions on th page. so he cannot understand flow/functionality of the test.

2) SSL Handling:
-----------------------------------------------------------
SSL - Secure sockets Layer
 to access some web browser we need some ssl certificates

ChromeOptions option = new ChromeOptions();
options.setAcceptInsecureCerts(true);// accepts SSL Certificates
WebDriver driver = new ChromeDriver(options);

-----------------------------------------------------------------------
