Throws keyword
---------------
The Java throws keyword is used to declare an exception.
Throws keyword can be used to declare that a method is not going to handle the checked exception but caller need to handle it


throw keyword
--------------
The Java throw keyword is used to throw an exception explicitly.
By using keyword you can create an instance of any exception, either a RuntimeException or a unchecked
